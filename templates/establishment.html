How to read this

TRC = recordable cases × 200,000 ÷ hours worked, i.e. cases per 100 full-time workers. TRC here measures nonfatal recordable injuries and illnesses; fatalities are shown separately. {% if e.bench %}Among {{ e.bench.n }} reporting sites in this industry{% if e.bench_code != e.naics %} (NAICS {{ e.bench_code }} group){% endif %}, the median is {{ e.bench.trc_med|fmt }} and the 75th-percentile threshold is {{ e.bench.trc_q3|fmt }} (tied rates mean this is not an exact rank) — a comparison with the sites that file here, not with all U.S. employers.{% endif %} Rates at a single site swing with the denominator — one nonfatal recordable case over 500,000 hours worked produces a rate of 0.4 — so read the three-year row together, and compare with the company's other sites before drawing conclusions.
